# Job Automation Agent

A simple Flask web application for managing candidates, jobs, job matching, applications, and analytics.

## Technologies
- Python
- Flask
- SQLite

## How to Run

```bash
pip install -r requirements.txt
python app.py
```

Open:

`http://127.0.0.1:5000`

## Main Features
- Candidate management
- Job management
- Candidate-job skill matching
- Match score calculation
- Resume and cover-letter generation
- Application tracking
- Analytics dashboard

The SQLite database is created automatically when the application runs.
